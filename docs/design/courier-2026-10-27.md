## 3. Arcade for everything

B3, verbatim (`bsv-stack-lean` `docs/charters/broadcaster.md:17`): "**Submit to the instances the host names and record every word per instance.** One submission per instance (by default three: the hosted Arcade, GorillaPool's ARC, TAAL's ARC), each in a body form that instance parses at its pin (EF or raw to Arcade, never a BEEF; raw, EF or BEEF to ARC, never the AtomicBEEF prefix: #63). No instance is the authority and instances never vote: two instances agreeing are two hints, a disagreement between instances is recorded and settled only by a proof or by headers." Under the owner's word the host names Arcade (and later the node); ARC is not named.

B5, verbatim (`:19`), its rule sentences: "**A policy refusal is a hint, never a word.** [...] An instance's refusal for its own policy (ARC's 465 fee too low, 473 cumulative fee, 474 size, 471 its frozen list, the 46x its validator answers before any node sees the transaction; Arcade's 400 carrying `status` 460 to 475; a node's policy refusal relayed in a 200 body as REJECTED) is `HintStatus.rejected` with the code and the instance's text as the reason. It is never `Word.rejected`, which is written for one class only, a transaction invalid under the node's rules established by running them locally (the sibling's evaluator), and never any chain word."

## 4. The break-glass switch

| part | the design `[D]` |
|---|---|
| the switch | a var `EXPLORER_BREAK_GLASS`, absent or `off` by default; `on` only by a deploy on the keeper's act, never a secret (a secret cannot shadow a var, `wrangler.toml:37-38`, and a deploy leaves a record) |
| the ladder | WhatsOnChain, Bitails, Bananablocks, through `bsv-courier`'s explorer rungs only; Bananablocks with the overlay's routes and quota: `/tx/{txid}/hex` and `/txo/{txid}/{vout}/spend`, 60 requests a minute, no proof route (`proof_fetcher.rs:60, 761, 2603, 2617` at `9a0f3c2`) |

| the architecture test | an allowlist, not a name check: `worker::Fetch` and every other outbound send (`Fetch::`, a `web_sys` or `js_sys` fetch, any HTTP client crate) is allowed in the transport module only (`src/transport.rs`, the Worker's `Transport` of section 5, through which Arcade's, the header service's and the explorer rungs' requests all go); every other module under `src/` that names one fails. How it reaches the source: a host test (`tests/architecture.rs`) walks `src/` at test time from `CARGO_MANIFEST_DIR`, reads each `.rs` file, and matches the send forms line by line, comments stripped; the allowlist is one file, `tests/outbound_allowlist.txt`, one path a line. Reachability is the type's: the transport sends only for a `Rung`, and an explorer rung is built only by `BreakGlass::open` from the switch. A planted call is detected two ways: the test runs its matcher over a fixture string holding `worker::Fetch::Request(worker::Request::new(&env.var("X")?.to_string(), Method::Get)?)` and asserts a failure naming the line; and a planted send in any real module fails the walk with its file and line (#41's exit test); the walk resolves `use` aliases, so `use worker::Fetch as F` counts as the symbol |
| the Miniflare witnesses | `tests/worker_tracker_rule.mjs` and `tests/worker_beef_at_rest.mjs` run with an `outboundService` that throws on any WhatsOnChain, Bitails or Bananablocks host and records it; the run fails on one; a third case sets the switch on and asserts every explorer read left its `monitor_events` row |

## 5. The courier crate for the keeper: `bsv-courier` (named by the owner's word of 2026-10-27 13:0xZ; `Calhooon/bsv-courier` at 3765dda)

One crate, native and Workers targets, its own repository (the keeper's relay, 12:4xZ). The transport is a trait so the Worker supplies `worker::Fetch` and native supplies its own client. Sketch `[D]`:

```rust
pub enum Rung { Arcade(Instance), Node(Instance), Headers(Url), Woc, Bitails, Bananablocks }
pub enum Question { Proof(Txid), RawTx(Txid), Status(Txid), Spender(OutPoint), TipHeight, HeaderAt(u32), HeaderByHash(Hash), Policy }
pub enum Outcome<T> { Found(T), NotFound, Fault(String), Shape(String), CouldNotLook, Skipped }
pub struct Read<T> { pub rung: &'static str, pub question: Question, pub outcome: Outcome<T>, pub ms: u32, pub caller: &'static str }
pub trait Transport { async fn get(&self, url: &str, headers: &[(&str, &str)]) -> Result<(u16, Vec<u8>), String>; async fn send(&self, url: &str, headers: &[(&str, &str)], body: &[u8]) -> Result<(u16, Vec<u8>), String>; }
pub trait Recorder { fn record<T>(&self, read: &Read<T>); }      // the host writes it (here: monitor_events)
pub trait Pacer { fn pace(&self, rung: &str) -> Result<(), Skip>; fn result(&self, rung: &str, status: Option<u16>); }
pub struct Ladder<'a> { rungs: Vec<Rung>, start: usize, switch: BreakGlass, pacer: &'a dyn Pacer, rec: &'a dyn Recorder }
impl Ladder<'_> { pub async fn ask<T>(&self, q: Question, caller: &'static str) -> Answer<T>; }
pub enum Answer<T> { Found(T, &'static str), NothingThere, CouldNotLook(Vec<Read<T>>) }
```
